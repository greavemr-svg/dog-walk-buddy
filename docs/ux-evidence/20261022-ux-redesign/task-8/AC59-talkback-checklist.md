# AC59 TalkBack walk-through checklist (run 20261022-ux-redesign)

For the release session on the reference phone (spec AC59, MVP AC50). Turn on TalkBack, then walk through each
screen in the **light** theme and again in the **dark** theme. Record pass or fail and a note for every row.

| 3 | Today, Avoid | As row 1 | | | |
