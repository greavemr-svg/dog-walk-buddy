# Dog Walk Buddy v0.1.0

First release of Dog Walk Buddy, Android phones only (minSdk 29, targetSdk 36), English (UK).
It ships the MVP (run `20261019-dog-walk-buddy-mvp`, epic #7) together with the "Field Kit" UX redesign (run `20261022-ux-redesign`, epic #31). The MVP was never released on its own: its release PR #28 was put on hold, and the owner chose to ship one release from `feature/20261022-ux-redesign` that carries both. The release PR for this version supersedes PR #28.

- Specs: `docs/specs/20261019-dog-walk-buddy-mvp.md` (MVP AC1-AC53, all still in force) and `docs/specs/20261022-ux-redesign.md` (AC1-AC67).
- Designs: `docs/design/20261019-dog-walk-buddy-mvp.md` and `docs/design/20261022-ux-redesign.md`.
- ADRs: 0001-0005 (MVP) and 0006-0008 (redesign) in `docs/adr/`.

## Version choice
0.1.0 (versionCode 1): this is still the first release. There is no earlier tag, so there is nothing to bump from, and `version.properties` already holds 0.1.0 / 1 and is unchanged. It is kept below 1.0.0 because some on-phone checks are still outstanding (see Known issues). Moving to 1.0.0 is the owner's decision.

## What's new
MVP features:
- **Walk check:** a one-glance Go / Caution / Avoid rating from MET Norway forecasts, with the best window in the next 12 hours. It uses approximate location and a cached check, and an "About this advice" screen names the guidance sources. Advice is guidance, not veterinary advice.
- **Dog profile:** one dog with name, breed, photo and a heat-sensitivity setting (Normal / Sensitive) that makes heat warnings stricter.
- **Walk recording:** start and stop in one tap, works offline, records duration, distance and GPS route through a foreground service.
- **History:** walk list, weekly totals (walks, time, distance) and delete.
- **Walk detail:** the route drawn on a street map.
- **Privacy:** a Privacy screen and "Delete all my data".
- **Accessibility:** large touch targets, bright-sunlight theme, TalkBack labels.

Field Kit redesign (what the app looks like in this release):
- **Field Kit theme:** the owner's blue "Field Kit" design on every screen, with a designed light and dark mode that follows the phone setting. Fonts (Bricolage Grotesque, Figtree) and icons (Material Symbols) are bundled in the app, so nothing is downloaded at runtime (ADRs 0006, 0007, 0008). Accessibility floors (MVP AC50-AC53) are unchanged.
- **Bottom navigation:** Today, Walks and Dog tabs replace the home screen's list of link buttons. The Dog tab shows your dog's name.
- **Today:** a large hero rating card with a factor grid (whole-number values), a best-window card, a 12-hour forecast strip, a footnote linking to "About this advice", and a Start walk button kept within thumb reach. Designed "Can't check", location and precise-location states.
- **Recording:** an always-dark screen with an h:mm:ss timer, stat cards and a live route line.
- **Walks:** a this-week card with day dots, walks grouped by week, a "More" menu on each row and a confirmation sheet for delete.
- **Walk detail:** an edge-to-edge map with a detail sheet and delete flow. The map logo and attribution stay visible above the sheet.
- **Dog profile:** photo row, counters, heat-sensitivity radio cards and Save.
- **About:** a heat-sensitivity thresholds table.
- **Privacy:** shown as cards under the heading "Privacy & your data", with a confirmation sheet for "Delete all my data".
- **Copy:** only the owner-approved copy changes listed under "Approved copy" in the redesign spec. Rating rules, data handling, privacy and offline behaviour are unchanged.

## Fixes
- Walk detail map: MapLibre logo and attribution button kept visible (#26, PR #27).
- Recording timer: no longer drifts and skips a second every few minutes; it now ticks on whole seconds (#48, PR #49).
- Today: if Android refuses the network-status callback, the screen no longer fails; it falls back to the connectivity read on open (#48, PR #49; security R-02, resolved).

## Privacy
- Location, walks and the dog profile stay on the device. No accounts, no backend, no analytics or tracking. Backup is disabled (`allowBackup=false`).
- Weather requests go to `api.met.no` over HTTPS with coordinates rounded to 2 decimals and an identifying User-Agent.
- Map tiles come from `tiles.openfreemap.org`. The tile server sees the IP address and the tile coordinates viewed. Tile requests carry only the app User-Agent.
- Photos are re-encoded without EXIF and stored privately.
- Permissions: 7, none for background location.
- The redesign adds no network host, permission, dependency or exported component.

Open security findings (no Critical or High):

- R-08 (Low): an identifier of the owner's own test phone was committed in the run state file. It has been redacted from the current file but remains in `feature/20261022-ux-redesign` history. Cosmetic and backlog items (from the MVP and from redesign reviews):
- A recovered walk shows a 0:00 duration (MVP).
- MVP note: the h:mm duration format is ambiguous for short walks (no label). The Recording timer now shows h:mm:ss; other duration displays were not re-assessed for this note.
- At maximum font and display size the map attribution box may overlap the MapLibre logo (MVP; re-checked in P5).
- Each walk row's "More" button is read by TalkBack as just "More"; a per-walk label needs an owner copy decision.
- About: the fixed MVP heat-threshold sentence still wraps "Avoid from 25 / °C" on narrow screens; changing it needs an owner copy decision.
- About thresholds table: all 9 header cells are marked as headings, which crowds TalkBack heading navigation (checked in P4).
- On walk detail the map label can sit under the status bar (no top scrim).
- The Dog tab label stays "Dog" if reading the profile fails once; the name returns after restarting the app.
- Code-quality follow-ups from reviews (no user impact found): exception handling breadth in the Today connectivity collector, recording timer `remember` keys, a test helper's static counters, 24-hour format read once per screen, status-bar style ownership, profile field semantics.
- Performance: cold start is about 50 ms (+7 %) slower than the MVP build on the phone, within the limit. The walk detail map is still the memory peak (MapLibre).
- The release build is unsigned unless `DWB_KEYSTORE_*` environment variables are set. Publishing to Google Play is a manual owner action.

## Upgrade and rollback
- Upgrade: first release, there is no earlier version. Room schema version 1 (`app/schemas/`); the redesign adds one read-only query and no schema change, so there are no migrations. `fallbackToDestructiveMigration` is forbidden by ADR 0004, so future schema changes need tested `Migration` objects.
- Rollback before shipping: close the release PR without merging. After shipping: revert the release merge commit on `main` through a revert PR and issue a new build. Users can reinstall a previous build. Because the data is local-only and the schema is version 1, there is no data migration to reverse. Uninstalling removes all app data.
